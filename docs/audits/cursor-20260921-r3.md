## 本轮关闭的反例

### ASTRA-20260921-014 — fixed — `3ed50d39`
动作、合约、手数按单条原子意图校验：`TRADE_ACTION_RE` 计动作；多于 1 个动作 / 合约 / 手数 token → `multi-intent`。全句 `？/?/吗/么/呢/可以吗/风险是什么` → `question-intent`。句后 `不要下单` 或「开|平 … 不要」→ `negated-intent`。`localReply` 映射中文拒绝，不建 pending。
- 前：`开多 rb2610 100手可以吗？` 与 `开多 rb2610 3手的风险是什么？不要下单。` 各生成 pending；`开多 rb2610 1手，开空 cu2701 2手` 拼成错误 `open-short rb2610 1手`。
- 后：三句均为 `reject`；比赛会话 pending/fills 不变。`开空 cu2701 5手` 仍 `place` `open-short` 5 手。R2 已过的 `-3手` / 短「不要开多」保持拒绝。

### ASTRA-20260921-008 — fixed — `3ed50d39`
`parseCsv` 增加 after-quoted 状态：闭引号后只允许空白、逗号、换行/EOF；其它字符 `trailing-after-quote` 400。`addDataset` 先解析后落库，失败不新增数据集。
- 前：`"abc"def` 拼成 `abcdef` 并导入。
- 后：`parseCsv('a,b\n"abc"def,1\n')` throw；`addDataset` 拒绝且 datasets 数量不变。`"  padded  "` 与 `""` 转义仍通过。

### ASTRA-20260921-033 — fixed — `51a36868`
开发 launcher 显式 opt-in，不恢复默认 Vite 信任。
- 前：裸 `npm run dev` 起 5173，写会话 `forbidden-origin`。
- 后：`package.json` `dev` / `dev:api` 含 `QS_ALLOW_DEV_ORIGINS=1`；`start` 不含。README 写明 `npm run dev` 授权 Vite 开发端口，`npm start` 仍拒绝 5173/4173。活进程 `npm start`：5173 bootstrap **403**，3198 **200**。
